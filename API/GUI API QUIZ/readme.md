# QuizMaster - Modern Trivia Quiz App

A modern, sleek True/False quiz application that pulls questions from the Open Trivia Database API with a fallback to default questions if offline.

## Features

- 🎯 10 True/False questions per quiz
- 🌐 Online API integration with offline fallback
- 🎨 Modern UI with smooth animations
- 📊 Real-time score tracking
- ✅ Immediate answer feedback
- 🖱️ Button hover effects
- 📱 Responsive design

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/quizmaster.git
   cd quizmaster
   ```
